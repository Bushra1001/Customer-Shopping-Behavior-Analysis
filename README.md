# Customer-Shopping-Behavior-Analysis
End-to-end Data Analytics project using Python, SQL, and Power BI to analyze customer shopping behavior, uncover business insights, and build an interactive dashboard.

## Project Overview

This project analyzes customer shopping behavior using transactional data from **3,900 customer purchases**. The objective is to uncover purchasing patterns, customer preferences, and business opportunities through data cleaning, SQL analysis, and interactive dashboarding.

The project demonstrates an end-to-end data analytics workflow using **Python, SQL, and Power BI**.

---

## Objectives

- Analyze customer purchasing behavior
- Identify top-performing product categories
- Understand customer demographics and spending patterns
- Evaluate subscription and discount effectiveness
- Generate actionable business recommendations

## Key Insights

- Clothing generated the highest revenue.
- Only 7.3% of customers are subscribed.
- Young Adults contributed the highest sales.
- Average Purchase Amount: **$59.76**
- Credit Card was the preferred payment method.
